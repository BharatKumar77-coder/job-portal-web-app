# Job Portal Web Application 🚀

A full-stack Job Portal built using MERN stack.

## Features
- User authentication (JWT)
- Job posting & job application
- Company management
- Resume & logo upload
- Admin dashboard

## Tech Stack
Frontend:
- React
- Tailwind CSS
- Redux Toolkit

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Multer & Cloudinary

## Project Structure
job portal/
├── frontend/
└── backend/
